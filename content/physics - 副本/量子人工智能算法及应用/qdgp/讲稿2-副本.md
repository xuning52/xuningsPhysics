# QDGP

## 2.1 是什么？

### 1. 核心定位：量子增强的“图像修复师”

首先要明确 QDGP 是一种**利用量子线路来增强现有的深度生成模型的技术 。**
经典 DGP：高斯分布作为潜空间
QDGP 引入了**量子潜空间**，让模型能找到更多样、更精确的图像特征 。

- **它的任务：** 解决“逆问题”（Inverse Problems），比如把模糊变清晰（超分）、给黑白照上色、或者补全缺失的图片 。

### 2. 三大核心优势

1. **更强的泛化能力 (Generalization)：** 量子潜空间能有效处理“分布外”（Out-of-distribution）的数据 。~~例如，当用训练于自然图像的模型去修复生物标本图（如蝴蝶或蜂翅）时，QDGP 的表现远超传统方法 。
    
2. **更高的生成多样性 (Diversity)：** 由于量子潜空间是分布在极其广阔的希尔伯特空间（Hilbert space）中，它能解耦模型固有模式与潜码之间的强耦合，从而生成更多样化的修复结果~~（比如在补全图片时尝试更多种可能的细节） 。
    
3. **应对算力瓶颈：** QDGP 的设计非常适合目前的“近期待量子设备”（NISQ） 。它将大规模的计算交给经典的神经网络，量子线路只负责最核心的潜码生成 。

```

│  ├─ biggan.py          <-- 经典骨干：预训练的图像合成网络

│  └─ *.JPEG             <-- 用于验证泛化能力的测试图像
│
├─ qtrainer.py           <-- 训练逻辑：量子与经典参数的联合优化器

```

##### 整体串联：如果你运行 `main.py`

当你启动 `main.py` 时，后台发生的“故事”是这样的：

1. **初始化**：`main.py` 读取配置，从 `models/` 加载量子线路和预训练的 BigGAN。
    
2. **主循环**：
    
    - `QSampler.py` 运行，吐出量子编码 $z$。
        
    - `biggan.py` 运行，根据 $z$ 生成当前图像。
        
    - `losses.py` 运行，判断这张图距离完美的修复/重构目标差多少。
        
    - `qtrainer.py` 发动 `Adam`，根据 Loss 回传的梯度，把 `QSampler.py` 里的量子门角度 $\theta$ 拧一点点。
        
3. **结果**：经过数百次循环，$\theta$ 被调整到了最优状态，此时 `biggan.py` 输出的图像就是你最终想要的重构结果。

#### 1. 核心架构组件

要实现qdgp代码逻辑，需要准备以下三个模块：

- **量子模块 (PQC)**：~~使用 Python 库（如 `PennyLane` 或 `Qiskit`）~~构建一个**参数化量子电路 (Parameterized Quantum Circuit)**。输出一串量子测量值，作为潜在编码（Latent Code）$z$。
    
- **经典生成器 (Generator)**：进行绘图（例如 `BigGAN`、`StyleGAN` 或 `DCGAN`）。
    
- **优化器 (Optimizer)**：用于在推理过程中不断调整量子电路的参数。

### 1. 线路的三个阶段
==线路分为分为三个阶段：==
**初始态准备，**参数化旋转层，**强纠缠层

- 初始态准备：最左边的 $|0\rangle$ 表示所有量子比特初始化为 0 态。
    
- **参数化旋转层由$R_y$ 门构成**：
        
    - **$\theta$ 就是我们要优化的参数**。每个量子比特在每一层都有一个独立的 $\theta$。
        
- **强纠缠层，CNOT 门构成**：
    - 让不同的量子比特产生“纠缠”。
        
    - 在代码逻辑中，这保证了输出的 $z$ 向量各个维度之间具有**量子关联性**。是提升 AI 泛化能力的关键。

### 2. $Z$ 测量

- **测量（Measurement）**：最右边的仪表盘符号。
    
- **计算公式**：
    
    $$z_j = \langle \psi(\theta) | \hat{M}_j | \psi(\theta) \rangle$$
    ==接下来是从量子到经典的测量：
    - 这个公式代表对第 $j$ 个量子比特进行测量，得到一个 \[-1, 1] 之间的期望值。
        
- **得到 $z$**：如果你有 100 个量子比特，你就能得到一个长度为 100 的向量 $z$。
