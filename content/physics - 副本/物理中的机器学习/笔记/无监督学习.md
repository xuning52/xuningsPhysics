![[2020c7894f7954f63370da90a20be411.jpg]]PPT 下半部分给出了准备数据的 Python 代码：

```python
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
```

> **做什么**：从 Python 的机器学习库（scikit-learn）中扔出两个工具：一个是自带的鸢尾花数据集，另一个是用来切分数据的工具。

```python
iris = load_iris(as_frame=True)
```

> **做什么**：把数据加载进来，并让它以表格（DataFrame）的形式呈现，方便观察。

```python
X = iris.data[["sepal length (cm)", "sepal width (cm)"]]
y = iris.target
```

> **做什么**：
> 
> - **`X` (特征)**：只选了“花萼长度”和“花萼宽度”这两列作为输入数据。
>     
> - **`y` (标签)**：代表花朵的真实品种（通常用 0, 1, 2 分别代表三种花）。
>     

```python
X_train, X_test, y_train, y_test = train_test_split(X, y, stratify=y, random_state=0)
```
骨架：X_train, X_test, y_train, y_test = train_test_split(X, y)
其中X是矩阵，大写；y是向量，小写

> **做什么**：把手里的数据分成两份：
> 
> - **训练集 (`X_train`, `y_train`)**：用来给算法“看”和“学习”的课本。
>     
> - **测试集 (`X_test`, `y_test`)**：留起来不让算法看，等它学完了用来当做“期末考试”，测测它的分类准确率。
>     
> - `stratify=y` 的意思是确保训练集和测试集里，三种花的比例是一样的，防止偏科。
