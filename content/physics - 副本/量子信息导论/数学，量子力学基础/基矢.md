# 单量子比特

$|0\rangle = \begin{pmatrix} 1 \\ 0 \end{pmatrix}$

$|1\rangle = \begin{pmatrix} 0 \\ 1 \end{pmatrix}$

# 双量子比特

- **$|00\rangle$ (也写作 $|0\rangle \otimes |0\rangle$)**
    
    $$\begin{pmatrix} 1 \\ 0 \end{pmatrix} \otimes \begin{pmatrix} 1 \\ 0 \end{pmatrix} = \begin{pmatrix} 1 \times 1 \\ 1 \times 0 \\ 0 \times 1 \\ 0 \times 0 \end{pmatrix} = \begin{pmatrix} 1 \\ 0 \\ 0 \\ 0 \end{pmatrix}$$
    
- **$|01\rangle$ (也写作 $|0\rangle \otimes |1\rangle$)**
    
    $$\begin{pmatrix} 1 \\ 0 \end{pmatrix} \otimes \begin{pmatrix} 0 \\ 1 \end{pmatrix} = \begin{pmatrix} 1 \times 0 \\ 1 \times 1 \\ 0 \times 0 \\ 0 \times 1 \end{pmatrix} = \begin{pmatrix} 0 \\ 1 \\ 0 \\ 0 \end{pmatrix}$$
    
- **$|10\rangle$ (也写作 $|1\rangle \otimes |0\rangle$)**
    
    $$\begin{pmatrix} 0 \\ 1 \end{pmatrix} \otimes \begin{pmatrix} 1 \\ 0 \end{pmatrix} = \begin{pmatrix} 0 \times 1 \\ 0 \times 0 \\ 1 \times 1 \\ 1 \times 0 \end{pmatrix} = \begin{pmatrix} 0 \\ 0 \\ 1 \\ 0 \end{pmatrix}$$
    
- **$|11\rangle$ (也写作 $|1\rangle \otimes |1\rangle$)**
    
    $$\begin{pmatrix} 0 \\ 1 \end{pmatrix} \otimes \begin{pmatrix} 0 \\ 1 \end{pmatrix} = \begin{pmatrix} 0 \times 0 \\ 0 \times 1 \\ 1 \times 0 \\ 1 \times 1 \end{pmatrix} = \begin{pmatrix} 0 \\ 0 \\ 0 \\ 1 \end{pmatrix}$$

- **$\Phi$ 族**（00 和 11）：就占领矩阵的四个角。
	- $$|\Phi_{\pm}\rangle = \frac{1}{\sqrt{2}} (|00\rangle \pm |11\rangle)$$

$$(a|01\rangle + b|10\rangle) (a^*\langle 01| + b^*\langle 10|)$$
$$= |a|^2 |01\rangle\langle 01| + ab^* |01\rangle\langle 10| + a^*b |10\rangle\langle 01| + |b|^2 |10\rangle\langle 10|$$

想象一个 $4 \times 4$ 的大矩阵。因为只有 $|01\rangle$ 和 $|10\rangle$ 参与，所以第 **1** 行、第 **4** 行、第 **1** 列、第 **4** 列全部都是 **0**。

你只需要把系数填进中间的那个小方阵：

- **左上 ($|01\rangle\langle 01|$)**: 填 $a \cdot a^*$
    
- **右上 ($|01\rangle\langle 10|$)**: 填 $a \cdot b^*$
    
- **左下 ($|10\rangle\langle 01|$)**: 填 $b \cdot a^*$
    
- **右下 ($|10\rangle\langle 10|$)**: 填 $b \cdot b^*$
    
$$\begin{pmatrix} 0 & 0 & 0 & 0 \\ 0 & \mathbf{aa^*} & \mathbf{ab^*} & 0 \\ 0 & \mathbf{a^*b} & \mathbf{bb^*} & 0 \\ 0 & 0 & 0 & 0 \end{pmatrix}$$
