# Deutsch算法
## 单比特Deutsch问题

假设有一个黑盒函数 $f: \{0, 1\} \rightarrow \{0, 1\}$。这个函数接受一个比特的输入，并输出一个比特。

根据数学定义，这样的函数只有 4 种可能：

- **常数函数 (Constant):** $f(0) = f(1)$（输出总是 0 或总是 1）。
    
- **平衡函数 (Balanced):** $f(0) \neq f(1)$（输出一半是 0，一半是 1）。
    

**目标：** 判断这个函数是“常数”还是“平衡”的。

- **经典算法：** 你必须查询黑盒 **2 次**（分别计算 $f(0)$ 和 $f(1)$）才能得出结论。
    
- **Deutsch 算法：** 只需要查询黑盒 **1 次**。
![[Pasted image 20260331101939.png]]
PPT 顶部的表格定义了黑盒函数 $f(x)$ 的四种可能情况
在**经典**逻辑下，你必须看 $f(0)$ 也要看 $f(1)$ 才能确定它是哪一类。但量子计算的目标是：**只输入一次叠加态，直接得出结论。**

**叠加态公式：** $\frac{1}{\sqrt{2}} [(-1)^{f(0)}\ket{0} + (-1)^{f(1)}\ket{1}]$ 这个公式是主粒子的状态。注意，函数的输出 $f(x)$ 变成了系数里的指数。

- **A 类（常数）：** 由于 $f(0) = f(1)$，两个项前面的正负号是一样的。提取公因子后，状态变成了 $\pm \frac{1}{\sqrt{2}}(\ket{0} + \ket{1})$。这其实就是 $\ket{+}$ 态。
    
- **B 类（平衡）：** 由于 $f(0) \neq f(1)$，两个项前面的正负号一定相反。状态变成了 $\pm \frac{1}{\sqrt{2}}(\ket{0} - \ket{1})$。这其实就是 $\ket{-}$ 态。

**量子力学如何用“数学符号”来表达“相位翻转”**。

1. 它要求啥？（计算目标）
**两个量子态相遇时，它们产生的“相位因子”到底是 $+1$ 还是 $-1$？**
在 Deutsch-Jozsa 算法中，这个相位因子决定了最后测量时，波形是相长干涉（变强）还是相消干涉（抵消）。

2. 咋点积完了还 mod 2？（奇偶校验）
#二进制点积 的公式是 $$x \cdot y = \sum x_i y_i$$。
- **为什么点积？** 它在找 $x$ 和 $y$ 里面**同时为 1** 的位置有几个。
- **为什么要 mod 2？** 因为在量子相位里，我们只关心**奇偶性**。

3. 那个 $-1$ 又是啥？（相位映射）
**把二进制逻辑转化成物理相位。**
PPT 最后的公式是 $(-1)^{x \cdot y}$：
- 如果点积 $\text{mod } 2 = 0$（偶数），那么 $(-1)^0 = 1$。**相位为正。**
- 如果点积 $\text{mod } 2 = 1$（奇数），那么 $(-1)^1 = -1$。**相位翻转为负。**

### **Deutsch-Jozsa 算法的全流程大总结**
它把刚才咱们聊的辅助粒子、叠加态、点积公式全都串在了一起，展示了量
![[eba88a808d75b9c30524602047d1ae25.jpg]]
![[4118a074d0e24ad9bc26116e6c6d1eac.jpg]]
- **初始化 (Preparation)** 把机器清零。
	准备 $n$ 个 $\ket{0}$（主寄存器）和 1 个 $\ket{1}$（辅助寄存器）。不初始化，后面的计算就没有基准。
	
- **第一步：全员叠加。** 利用 $H$ 门把所有可能的输入 $x$ 全部变成叠加态。
    
- **第二步：相位标记。** 穿过黑盒时，黑盒并不直接改变结果，而是给每个分支贴上一个正负号（相位 $(-1)^{f(x)}$）。
    
- **第三步：相消干涉。** 再次作用 $H$ 门。
    
    - 如果函数是**常数**，所有的波峰方向一致，最后汇聚到 **全 0 态 ($\ket{00\dots0}$)**。
        
    - 如果函数是**平衡**的，一半正波一半负波，它们会在全 0 态的位置**完美抵消**。
	
- **测量 (Measurement)** 眼睛去看结果。量子态在测量前是不确定的，这一步是把量子的概率变成了确定的 $0$ 或 $1$

# grover算法

原理：振幅放大
oracle黑盒函数：对目标态操作
扩散算子

算法步骤：
假设我们要从 $N=2^n$ 个状态中找到一个目标状态 $|w\rangle$。

## 第一步：初始化

将所有量子比特初始化为均匀叠加态 $|s\rangle$。此时，每个状态出现的概率是均等的。

$$|s\rangle = \frac{1}{\sqrt{N}} \sum_{x=0}^{N-1} |x\rangle$$

## 第二步：Grover 迭代（重复约 $\frac{\pi}{4}\sqrt{N}$ 次）

每次迭代包含两个核心操作：

1. **Oracle（量子查询）：**
    
    Oracle 相当于一个“黑盒”，它会识别出目标状态 $|w\rangle$ 并将其相位的符号翻转（从正变负），而保持其他状态不变。
    
2. **扩散算子（Diffusion Operator）：**
    
    这一步也称为“关于平均值的反转”。它计算所有振幅的平均值，并将每个振幅关于该平均值进行翻转。由于目标状态的振幅在第一步被翻转成了负值，这一步操作会使其振幅显著增加，而其他状态的振幅则会略微减小。

$$|\phi\rangle = \cos\theta |\alpha\rangle + \sin\theta |\beta\rangle$$
第一步：反转目标态相位 ($P$ 算子)。图中$P = I - 2|\alpha\rangle\langle\alpha|$：反转目标态相位，系数1变成-1
第二步：应用扩散算子 ($D$ 算子)


解法：
直接代入公式，算出执行 $D(P|\phi\rangle)$ 后的新系数。


## **需要多少次迭代才能找到目标？**
- 初始角度通常很小（$\sin\theta = 1/\sqrt{N}$）。
- 每次迭代旋转 $2\theta$。
- 目标是让总角度接近 $\pi/2$（即完全重合到 $|\alpha\rangle$ 上）。
- 结论：迭代次数 $k \approx \frac{\pi}{4}\sqrt{N}$。
