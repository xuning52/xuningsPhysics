# 1. 量子信息：从 Bit 到 Qubit

量子信息的研究核心是如何利用量子力学的特性（叠加、相干、纠缠）来处理和传输信息。

- **量子比特（Qubit）：** 不同于经典比特的 0 或 1，Qubit 可以处于叠加态 $|\psi\rangle = \alpha|0\rangle + \beta|1\rangle$。这意味着一个 Qubit 在未测量前可以“同时”携带多种状态的信息。
    
- **量子纠缠（Quantum Entanglement）：** 这是量子信息的“加速器”。处于纠缠态的两个粒子，无论相距多远，其状态都存在强关联。这不仅是量子隐形传态（Teleportation）的基础，也是实现超快计算的关键。
    
- **无克隆原理（No-Cloning Theorem）：** 量子信息的一个基本法则——你无法完美地复制一个未知的量子态。这在经典信息中看似是限制，但在密码学中却是天然的防御盾牌。

## 问题一:简述量子不可克隆定理的证明过程?说明定理为何只对未知量子态有效?
![[Pasted image 20260430092240.png]]
θ已知，则可以制备


假设我们有一个“克隆机”（算符 $U$），它的任务是把一个未知态 $|\psi\rangle$ 复制到另一个空白态 $|0\rangle$ 上：

$$U(|\psi\rangle|0\rangle) = |\psi\rangle|\psi\rangle$$

1. **对于基础状态**：假设它能成功克隆垂直极化 $|\uparrow\rangle$ 和水平极化 $|\leftrightarrow\rangle$ 。
    
2. **对于叠加态**：如果我们输入一个叠加态 $|\phi\rangle = \alpha|\uparrow\rangle + \beta|\leftrightarrow\rangle$ 。
    
3. **线性的冲突**：
    
    - 根据**线性性质**，输出应该是：$\alpha|\uparrow\rangle|\uparrow\rangle + \beta|\leftrightarrow\rangle|\leftrightarrow\rangle$ 。
	    将 $|\phi\rangle = \alpha|\uparrow\rangle + \beta|\leftrightarrow\rangle$ 带入表达式 $|\phi\rangle|\phi\rangle$（即 $|\phi\rangle \otimes |\phi\rangle$）：
		$$|\phi\rangle|\phi\rangle = (\alpha|\uparrow\rangle + \beta|\leftrightarrow\rangle) \otimes (\alpha|\uparrow\rangle + \beta|\leftrightarrow\rangle)$$
		
		利用张量积的分配律，我们像做 $(a+b)(c+d)$ 一样展开：
		
		1. **第一项 $\times$ 第一项**: $\alpha|\uparrow\rangle \otimes \alpha|\uparrow\rangle = \alpha^2 |\uparrow\rangle|\uparrow\rangle$
		    
		2. **第一项 $\times$ 第二项**: $\alpha|\uparrow\rangle \otimes \beta|\leftrightarrow\rangle = \alpha\beta |\uparrow\rangle|\leftrightarrow\rangle$
		    
		3. **第二项 $\times$ 第一项**: $\beta|\leftrightarrow\rangle \otimes \alpha|\uparrow\rangle = \beta\alpha |\leftrightarrow\rangle|\uparrow\rangle$
		    
		4. **第二项 $\times$ 第二项**: $\beta|\leftrightarrow\rangle \otimes \beta|\leftrightarrow\rangle = \beta^2 |\leftrightarrow\rangle|\leftrightarrow\rangle$
		    
		
		将它们加在一起，得到完整展开式：
		
		$$|\phi\rangle|\phi\rangle = \alpha^2 |\uparrow\rangle|\uparrow\rangle + \alpha\beta |\uparrow\rangle|\leftrightarrow\rangle + \beta\alpha |\leftrightarrow\rangle|\uparrow\rangle + \beta^2 |\leftrightarrow\rangle|\leftrightarrow\rangle$$
	        
    - 但**完美的克隆**要求输出是：$|\phi\rangle|\phi\rangle = (\alpha|\uparrow\rangle + \beta|\leftrightarrow\rangle) \otimes (\alpha|\uparrow\rangle + \beta|\leftrightarrow\rangle)$ 。
        
    - 展开后你会发现，完美克隆的结果里多出了交叉项（如 $\alpha\beta|\uparrow\rangle|\leftrightarrow\rangle$），这与线性演化的结果**不相等** 。
        

**结论**：除非 $\alpha$ 或 $\beta$ 有一个是 0（即你已经知道它是什么态了），否则你无法制造出一个通用的克隆机来复制任意状态 。

## 问题二:简述量子隐形传态的过程，分析其是否违反不可克隆定理?
**量子隐形传态（Quantum Teleportation）过程：**

1. **制备纠缠对**：Alice 和 Bob 各持有一个纠缠对中的粒子。
    
2. **贝尔态测量**：Alice 将待传输的未知量子态粒子与她手里的纠缠粒子进行联合测量（Bell State Measurement）。
    
3. **信息传输**：Alice 通过经典信道（比如打电话）告诉 Bob 她的测量结果（2比特信息）。
    
4. **状态恢复**：Bob 根据 Alice 的结果对自己手里的粒子进行相应的么正变换（旋转），从而恢复出原本在 Alice 那里的未知态。

**是否违反不可克隆定理？**

- **不违反**。因为在隐形传态过程中，当 Bob 成功恢复出量子态时，Alice 手里的原始量子态已经因为测量而**坍缩销毁**了。
    
- 量子态只是从 Alice 处“移动”到了 Bob 处，在任何时刻，全宇宙仍然只有一个该量子态的副本，因此完全符合不可克隆定理。

## 问题三:为何若不可克隆定理成立就可能实现超光速通信?

- **利用 EPR 纠缠对**：假设 Alice 和 Bob 各持有一个处于纠缠态的粒子 。
    
- **Alice 的测量选择**：Alice 可以选择测量极化的方向（比如垂直/水平，或者 45 度方向） 。一旦 Alice 测量，远在天边的 Bob 的粒子状态会瞬间坍缩到对应的基矢上 。
    
- **Bob 的克隆攻击**：
    
    - 正常情况下，Bob 无法通过单次测量知道 Alice 选了哪个方向，因为测量会改变量子态。
        
    - 但**如果克隆成立**，Bob 可以先将自己的粒子克隆成一万个副本，然后对这一万个副本进行各种方向的统计测量 。
        
    - 通过分析这些副本的统计分布，Bob 就能瞬间推断出 Alice 刚才选了哪个测量方向 。
        
- **结论**：这样 Alice 就能通过改变测量基准，瞬间把信息传给 Bob，从而实现**超光速通信** 。因此，不可克隆定理是宇宙因果律的“保镖”，防止了超光速现象的发生 。

## 克隆量子态的后果
如果能完美克隆一个量子态，就会产生两个严重的后果：

- **突破海森堡不确定性原理**：你可以对第一个副本测位置，对第二个副本测动量，从而同时精确知道两者 。
    
- **实现超光速通信**：利用 EPR 纠缠对，如果你能克隆其中的粒子并测量其精确状态，就能瞬间知道远方观察者做了什么测量，从而传递信息 。

### 基本原理

量子力学的**叠加态**和**不可克隆性**。

| **特性**   | **量子隐形传态 (Teleportation)** | **BB84 协议 (QKD)**  |
| -------- | -------------------------- | ------------------ |
| **载体**   | 需要一对**纠缠粒子**               | 只需要**单粒子**（单光子）    |
| **目的**   | 传输一个未知的量子态                 | 协商出一串随机密钥          |
| **经典通信** | 必须有，用来传测量结果                | 必须有，用来“对基”和纠错      |
| **实现难度** | **极高**（维持纠缠和贝尔态测量很难）       | **中等**（已经商用，如京沪干线） |

### 基矢构建

- **Z 基** **直角基 ($+$ 型)** 测量对应算符 $\sigma_z = \begin{pmatrix} 1 & 0 \\ 0 & -1 \end{pmatrix}$
	- 它对应的是计算基底 $|0\rangle$ 和 $|1\rangle$。
	- 在偏振中，通常定义 $|0\rangle$ 为水平偏振 ($H$)，$|1\rangle$ 为垂直偏振 ($V$)。
	- **算符：** $\sigma_z$。它的本征态就是 $|0\rangle$ 和 $|1\rangle$。

- **X 基** **对角基 ($\times$ 型)** 测量对应算符 $\sigma_x = \begin{pmatrix} 0 & 1 \\ 1 & 0 \end{pmatrix}$
	- 它对应的是叠加态 $|+\rangle$ 和 $|-\rangle$。
	- 在偏振中，这对应 $+45^\circ$ 和 $-45^\circ$。
	- **算符：** $\sigma_x$。它的本征态是 $|+\rangle = \frac{1}{\sqrt{2}}(|0\rangle + |1\rangle)$ 和 $|-\rangle = \frac{1}{\sqrt{2}}(|0\rangle - |1\rangle)$。

### 攻击
#### 截获-重发攻击：==eve引入的误差：25%==
$$误差 = (Eve 选对基矢的概率 \times 0) + (Eve 选错基矢的概率 \times Bob 测错的概率)$$

$$误差 = (\frac{1}{2} \times 0) + (\frac{1}{2} \times \frac{1}{2}) = \frac{1}{4} = 25\%$$
- **基矢匹配的情况 (50% 概率)：**
    
    - 如果 Eve 运气好，选了和 Alice 一样的基矢（概率 $1/2$），她测得准，发得也准。
        
    - 这种情况下，Bob 测得的结果和 Alice **完全一致**。
        
    - **误差：$0\%$**。
        
- **基矢不匹配的情况 (50% 概率)：**
    
    - 如果 Eve 选错了基矢（概率 $1/2$），她会强行让光子坍缩。
        
    - 比如 Alice 发的是 $+$ 基的 $|0\rangle$，Eve 用 $\times$ 基测，她会随机得到 $\times$ 基下的 $0$ 或 $1$。
        
    - Eve 把这个错的结果发给 Bob，Bob 用正确的 $+$ 基去测。
        
    - **关键点：** 此时 Bob 测得的结果是完全随机的（50% 是对的，50% 是错的）。
