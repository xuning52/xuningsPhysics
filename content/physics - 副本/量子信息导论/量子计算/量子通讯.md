# 1. 量子信息：从 Bit 到 Qubit

量子信息的研究核心是如何利用量子力学的特性（叠加、相干、纠缠）来处理和传输信息。

- **量子比特（Qubit）：** 不同于经典比特的 0 或 1，Qubit 可以处于叠加态 $|\psi\rangle = \alpha|0\rangle + \beta|1\rangle$。这意味着一个 Qubit 在未测量前可以“同时”携带多种状态的信息。
    
- **量子纠缠（Quantum Entanglement）：** 这是量子信息的“加速器”。处于纠缠态的两个粒子，无论相距多远，其状态都存在强关联。这不仅是量子隐形传态（Teleportation）的基础，也是实现超快计算的关键。
    
- **无克隆原理（No-Cloning Theorem）：** 量子信息的一个基本法则——你无法完美地复制一个未知的量子态。这在经典信息中看似是限制，但在密码学中却是天然的防御盾牌。

## 问题一:简述量子不可克隆定理的证明过程?说明定理为何只对未知量子态有效?
![[Pasted image 20260430092240.png]]
θ已知，则可以制备


假设我们有一个“克隆机”（算符 $U$），它的任务是把一个未知态 $|\psi\rangle$ 复制到另一个空白态 $|0\rangle$ 上：

$$U(|\psi\rangle|0\rangle) = |\psi\rangle|\psi\rangle$$

1. **对于基础状态**：假设它能成功克隆垂直极化 $|\uparrow\rangle$ 和水平极化 $|\leftrightarrow\rangle$ 。
    
2. **对于叠加态**：如果我们输入一个叠加态 $|\phi\rangle = \alpha|\uparrow\rangle + \beta|\leftrightarrow\rangle$ 。
    
3. **线性的冲突**：
    
    - 根据**线性性质**，输出应该是：$\alpha|\uparrow\rangle|\uparrow\rangle + \beta|\leftrightarrow\rangle|\leftrightarrow\rangle$ 。
	    将 $|\phi\rangle = \alpha|\uparrow\rangle + \beta|\leftrightarrow\rangle$ 带入表达式 $|\phi\rangle|\phi\rangle$（即 $|\phi\rangle \otimes |\phi\rangle$）：
		$$|\phi\rangle|\phi\rangle = (\alpha|\uparrow\rangle + \beta|\leftrightarrow\rangle) \otimes (\alpha|\uparrow\rangle + \beta|\leftrightarrow\rangle)$$
		
		利用张量积的分配律，我们像做 $(a+b)(c+d)$ 一样展开：
		
		1. **第一项 $\times$ 第一项**: $\alpha|\uparrow\rangle \otimes \alpha|\uparrow\rangle = \alpha^2 |\uparrow\rangle|\uparrow\rangle$
		    
		2. **第一项 $\times$ 第二项**: $\alpha|\uparrow\rangle \otimes \beta|\leftrightarrow\rangle = \alpha\beta |\uparrow\rangle|\leftrightarrow\rangle$
		    
		3. **第二项 $\times$ 第一项**: $\beta|\leftrightarrow\rangle \otimes \alpha|\uparrow\rangle = \beta\alpha |\leftrightarrow\rangle|\uparrow\rangle$
		    
		4. **第二项 $\times$ 第二项**: $\beta|\leftrightarrow\rangle \otimes \beta|\leftrightarrow\rangle = \beta^2 |\leftrightarrow\rangle|\leftrightarrow\rangle$
		    
		
		将它们加在一起，得到完整展开式：
		
		$$|\phi\rangle|\phi\rangle = \alpha^2 |\uparrow\rangle|\uparrow\rangle + \alpha\beta |\uparrow\rangle|\leftrightarrow\rangle + \beta\alpha |\leftrightarrow\rangle|\uparrow\rangle + \beta^2 |\leftrightarrow\rangle|\leftrightarrow\rangle$$
	        
    - 但**完美的克隆**要求输出是：$|\phi\rangle|\phi\rangle = (\alpha|\uparrow\rangle + \beta|\leftrightarrow\rangle) \otimes (\alpha|\uparrow\rangle + \beta|\leftrightarrow\rangle)$ 。
        
    - 展开后你会发现，完美克隆的结果里多出了交叉项（如 $\alpha\beta|\uparrow\rangle|\leftrightarrow\rangle$），这与线性演化的结果**不相等** 。
        

**结论**：除非 $\alpha$ 或 $\beta$ 有一个是 0（即你已经知道它是什么态了），否则你无法制造出一个通用的克隆机来复制任意状态 。

## 问题二:简述量子隐形传态的过程，分析其是否违反不可克隆定理?
**量子隐形传态（Quantum Teleportation）过程：**

1. **制备纠缠对**：Alice 和 Bob 各持有一个纠缠对中的粒子。
    
2. **贝尔态测量**：Alice 将待传输的未知量子态粒子与她手里的纠缠粒子进行联合测量（Bell State Measurement）。
    
3. **信息传输**：Alice 通过经典信道（比如打电话）告诉 Bob 她的测量结果（2比特信息）。
    
4. **状态恢复**：Bob 根据 Alice 的结果对自己手里的粒子进行相应的么正变换（旋转），从而恢复出原本在 Alice 那里的未知态。

**是否违反不可克隆定理？**

- **不违反**。因为在隐形传态过程中，当 Bob 成功恢复出量子态时，Alice 手里的原始量子态已经因为测量而**坍缩销毁**了。
    
- 量子态只是从 Alice 处“移动”到了 Bob 处，在任何时刻，全宇宙仍然只有一个该量子态的副本，因此完全符合不可克隆定理。

## 问题三:为何若不可克隆定理成立就可能实现超光速通信?

- **利用 EPR 纠缠对**：假设 Alice 和 Bob 各持有一个处于纠缠态的粒子 。
    
- **Alice 的测量选择**：Alice 可以选择测量极化的方向（比如垂直/水平，或者 45 度方向） 。一旦 Alice 测量，远在天边的 Bob 的粒子状态会瞬间坍缩到对应的基矢上 。
    
- **Bob 的克隆攻击**：
    
    - 正常情况下，Bob 无法通过单次测量知道 Alice 选了哪个方向，因为测量会改变量子态。
        
    - 但**如果克隆成立**，Bob 可以先将自己的粒子克隆成一万个副本，然后对这一万个副本进行各种方向的统计测量 。
        
    - 通过分析这些副本的统计分布，Bob 就能瞬间推断出 Alice 刚才选了哪个测量方向 。
        
- **结论**：这样 Alice 就能通过改变测量基准，瞬间把信息传给 Bob，从而实现**超光速通信** 。因此，不可克隆定理是宇宙因果律的“保镖”，防止了超光速现象的发生 。

## 克隆量子态的后果
如果能完美克隆一个量子态，就会产生两个严重的后果：

- **突破海森堡不确定性原理**：你可以对第一个副本测位置，对第二个副本测动量，从而同时精确知道两者 。
    
- **实现超光速通信**：利用 EPR 纠缠对，如果你能克隆其中的粒子并测量其精确状态，就能瞬间知道远方观察者做了什么测量，从而传递信息 。

## B92协议
BB84协议简化

### 1. 基矢构建
Alice 和 Bob 约定两个**非正交**的基向量（通常夹角为 45°）：

- **Alice 选择态：**
    
    - $\rightarrow$：代表水平态 $|H\rangle$（Alice 打算发比特 **0**）
        
    - $\nearrow$：代表 $+45^\circ$ 态 $|+\rangle$（Alice 打算发比特 **1**）
        
- **Bob 选择测量方式：**
    
    - $+$：代表直线基（包含 $|H\rangle$ 和 $|V\rangle$）。但在 B92 中，Bob 只关心 **$|V\rangle$** 的测量结果。
        
    - $\times$：代表对角基（包含 $|+\rangle$ 和 $|-\rangle$）。但在 B92 中，Bob 只关心 **$|-\rangle$** 的测量结果。


### 2. 传输过程

- **Alice**：随机生成 0 或 1，并发送对应的 $|H\rangle$ 或 $|+45^\rangle$ 给 Bob。
    
- **Bob**：随机选择测量基。但这里的操作很巧妙，Bob 不是去“读”状态，而是试图“排除”状态：
    
    - 为了检测是否为 0，他用**垂直基** $|V\rangle$ 测量（如果测得光子，说明肯定不是水平的 $|H\rangle$，即排除 0，推断是 1）。
        
    - 为了检测是否为 1，他用-45° 基 $|-45^\rangle$ 测量（如果测得光子，排除 1，推断是 0）。
        
![[49bd5c4e8805596b407f986140800a49.jpg]]

### 3. 筛选密钥

因为状态是非正交的，Bob 有很大概率测不到任何东西（即使选对了基）。

- **无结果**：Bob 什么都没测到（弃用）。
    
- **有结果（咔哒声）**：如果检测器响了，Bob 就能百分之百确定 Alice 发的是哪一个。例如，Bob 用垂直基测到了光子，那 Alice 一定发的是 $|+45^\rangle$。

简单来说，**“咔哒”响的前提是：Bob 选了一个能“杀掉”Alice 某种状态的测量方向，而且量子坍缩刚好发生了。**

总结一下：

- **不响**：什么都证明不了（可能是发了 $|H\rangle$，也可能是发了 $|+45^\circ\rangle$ 但运气不好没坍缩过去）。
    
- **响了**：是一个**强信号**，它瞬间杀死了 $|H\rangle$ 的可能性，石锤了 Alice 发的是 $|+45^\circ\rangle$。

|**Alice 发送 (比特)**|**Bob 用的滤光片**|**夹角**|**结果 (是否响)**|

|**0** (水平 $\rightarrow$)|**垂直** ($\uparrow$)|$90^\circ$|**绝对不响** (正交)|
|**1** ($45^\circ$ $\nearrow$)|**$-45^\circ$** ($\searrow$)|$90^\circ$|**绝对不响** (正交)|

图中的思考题给出了一个非常经典的态——**单态（Singlet State）**：

$$|\Psi_-\rangle = \frac{1}{\sqrt{2}}(|0\rangle_1|1\rangle_2 - |1\rangle_1|0\rangle_2)$$

这个态有个神奇的外号叫“全向反关联态”。

- **Alice** 对第一个粒子沿方向 $\vec{a}$ 测量（基准是 $\{|a\rangle, |a_\perp\rangle\}$）。
    
- **Bob** 对第二个粒子沿方向 $\vec{b}$ 测量（基准是 $\{|b\rangle, |b_\perp\rangle\}$）。
    
---

会出现哪些结果？概率为何？

这是最烧脑的部分，咱们直接看结论（你可以试着用刚才 B92 的投影逻辑去理解）：

A. 结果组合

总共有 4 种可能的组合情况：

1. Alice 测到 $+1$，Bob 测到 $+1$
    
2. Alice 测到 $+1$，Bob 测到 $-1$
    
3. Alice 测到 $-1$，Bob 测到 $+1$
    
4. Alice 测到 $-1$，Bob 测到 $-1$
    

B. 关键概率公式

如果 Alice 和 Bob 测量方向的夹角是 $\theta_{ab}$，那么他们拿到**相同结果**（即都是 $+1$ 或都是 $-1$）的概率是：

$$P(++) = P(--) = \frac{1}{2}\sin^2\left(\frac{\theta_{ab}}{2}\right)$$

他们拿到**相反结果**的概率是：

$$P(+-) = P(-+) = \frac{1}{2}\cos^2\left(\frac{\theta_{ab}}{2}\right)$$
- 怎么算？
	### 1. 写出单态 $|\Psi_-\rangle$ 的基底无关性
	
	单态 $|\Psi_-\rangle = \frac{1}{\sqrt{2}}(|01\rangle - |10\rangle)$ 有一个极其强悍的特性：**它是旋转不变的。**
	
	这意味着，无论你选哪个方向作为 $z$ 轴，它的形式永远不变。如果我们选 Alice 的测量方向 $\vec{a}$ 作为基准，那么这个态可以写成：
	
	$$|\Psi_-\rangle = \frac{1}{\sqrt{2}}(|a, a_\perp\rangle - |a_\perp, a\rangle)$$
	
	这里第一个位置是 Alice 的粒子，第二个是 Bob 的。
	
	### 2. 测量 Alice 后的波函数坍缩
	
	当 Alice 对第一个粒子进行 $\vec{a}$ 方向的测量时：
	
	- 如果 Alice 测到了 $|a\rangle$（结果为 $+1$）：
	    
	    根据纠缠特性，Bob 的第二个粒子会**瞬间坍缩**到其正交态 $|a_\perp\rangle$ 上。
	    
	- 此时，Bob 手里的态就是 $|\psi_{Bob}\rangle = |a_\perp\rangle$。
	    
	
	### 3. Bob 在 $\vec{b}$ 方向测量（投影过程）
	
	现在，Bob 拿着这个 $|a_\perp\rangle$ 态，去沿他自己的方向 $\vec{b}$ 测量。
	
	Bob 测到结果为 $+1$（即态为 $|b\rangle$）的概率，就是 $|a_\perp\rangle$ 在 $|b\rangle$ 上的**投影模平方**：
	
	$$P(\text{Bob测到}+1 | \text{Alice测到}+1) = |\langle b | a_\perp \rangle|^2$$
	
	现在我们来看几何关系：
	
	- $|a\rangle$ 和 $|a_\perp\rangle$ 夹角是 $180^\circ$（在布洛赫球上）。
	    
	- 在物理空间中，如果方向 $\vec{a}$ 和 $\vec{b}$ 的夹角是 $\theta$，那么量子态 $|a\rangle$ 和 $|b\rangle$ 之间的内积公式是：
	    
	    $$|\langle a | b \rangle|^2 = \cos^2\left(\frac{\theta}{2}\right)$$
	    
	- 因为 $|a_\perp\rangle$ 是 $|a\rangle$ 的正交反向态，它与 $|b\rangle$ 的物理夹角其实是 $180^\circ - \theta$ 或者说它是“垂直方向”的投影。
	    
	- 根据三角函数变换：
	    
	    $$|\langle b | a_\perp \rangle|^2 = \cos^2\left(\frac{180^\circ - \theta}{2}\right) = \cos^2(90^\circ - \frac{\theta}{2}) = \sin^2\left(\frac{\theta}{2}\right)$$
	    
	
	### 4. 组合得到最终概率
	
	别忘了，Alice 测到 $+1$ 本身就有 $1/2$ 的先验概率。
	
	所以，两人都测到 $+1$ 的总概率就是：
	
	$$P(++) = P(Alice=+1) \times P(Bob=+1 | Alice=+1) = \frac{1}{2} \sin^2\left(\frac{\theta}{2}\right)$$
	
	同理，如果 Bob 测到 $-1$（即测到 $|b_\perp\rangle$），因为 $|a_\perp\rangle$ 和 $|b_\perp\rangle$ 的物理夹角刚好是 $\theta$：
	
	$$P(+-) = \frac{1}{2} |\langle b_\perp | a_\perp \rangle|^2 = \frac{1}{2} \cos^2\left(\frac{\theta}{2}\right)$$
	
	---
	
	### 宁宁的总结逻辑：
	
	1. **纠缠**：Alice 测完了，Bob 拿到的就是 Alice 的**反向态**。
	    
	2. **投影**：Bob 拿这个反向态去测自己的方向，本质上就是做一次**基矢变换**。
	    
	3. **几何**：夹角 $\theta$ 决定了重合的程度。
	    
	
	**为什么公式里有 $\theta/2$？**
	
	这是因为自旋 $1/2$ 粒子的特殊性。你在实验室里把磁铁旋转 $\theta$ 角度，量子态在希尔伯特空间只旋转了 $\theta/2$。这是量子力学最让初学者抓狂但也最迷人的地方。
	
	这就是公式的由来，数学上其实就是**单态关联函数**的推导。这周作业要是让推这个，你就稳了！
	

- 直观解释：
	- **如果 Alice 和 Bob 的方向完全一致 ($\theta_{ab} = 0$)**：
	    
	    $\cos^2(0) = 1$，所以他们 100% 会拿到相反的结果（一个 $+1$ 一个 $-1$）。这就是单态的“守恒”——总自旋为 0。
	    
	- **如果方向完全相反 ($\theta_{ab} = 180^\circ$)**：
	    
	    $\sin^2(90^\circ) = 1$，他们反而 100% 会拿到相同的结果！
	    
	- **如果方向垂直 ($\theta_{ab} = 90^\circ$)**：
	    
    两人结果完全随机，相关性消失。
    

**总结思考题：**

对于单态 $|\Psi_-\rangle$ 来说，无论你在哪个基组测，只要两人的**基组相同**，结果必然**完美反关联**。这个特性就是 E91 能够通过贝尔不等式检测出 Eve 的基础。
