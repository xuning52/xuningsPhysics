==例题==
1. 整理表达式 $U$

我们观察表达式中的各项，并尝试通过因式分解来简化它：

$$U = X_1 Y_1 - X_1 Y_2 + X_2 Y_1 + X_2 Y_2 - X_2 - Y_1$$

我们将包含相同变量的项归类：

$$U = X_1 (Y_1 - Y_2) + X_2 (Y_1 + Y_2 - 1) - Y_1$$

----

2. 利用边界条件进行分类讨论

已知所有的变量 $X_1, X_2, Y_1, Y_2$ 都在 $[0, 1]$ 之间。我们可以对 $Y_1 + Y_2$ 的取值分两种情况讨论：

情况 A：$Y_1 + Y_2 \leq 1$

在这种情况下，项 $(Y_1 + Y_2 - 1) \leq 0$。

由于 $X_2 \geq 0$，为了让 $U$ 最大化，我们应该取 $X_2$ 的最小值，即 $X_2 = 0$。

此时式子简化为：

$$U \leq X_1 (Y_1 - Y_2) - Y_1$$

$$U \leq X_1 Y_1 - X_1 Y_2 - Y_1 = Y_1 (X_1 - 1) - X_1 Y_2$$

因为 $X_1 \leq 1$，所以 $(X_1 - 1) \leq 0$。且 $X_1, Y_2 \geq 0$。

由此可见，等号右边的两项均为非正数，因此 **$U \leq 0$**。

----

情况 B：$Y_1 + Y_2 > 1$

在这种情况下，项 $(Y_1 + Y_2 - 1) > 0$。

为了让 $U$ 最大化，我们取 $X_2$ 的最大值，即 $X_2 = 1$。

将 $X_2 = 1$ 代入原式：

$$U \leq X_1 (Y_1 - Y_2) + 1 \cdot (Y_1 + Y_2 - 1) - Y_1$$

$$U \leq X_1 Y_1 - X_1 Y_2 + Y_1 + Y_2 - 1 - Y_1$$

$$U \leq X_1 (Y_1 - Y_2) + Y_2 - 1$$

$$U \leq X_1 Y_1 - X_1 Y_2 + Y_2 - 1 = X_1 Y_1 + Y_2 (1 - X_1) - 1$$

由于 $X_1, Y_1 \leq 1$，则 $X_1 Y_1 \leq X_1$。代入得：

$$U \leq X_1 + Y_2 (1 - X_1) - 1$$

$$U \leq X_1 - 1 + Y_2 (1 - X_1) = (1 - X_1)(Y_2 - 1)$$

因为 $X_1 \leq 1 \implies (1 - X_1) \geq 0$，而 $Y_2 \leq 1 \implies (Y_2 - 1) \leq 0$。

正数乘以负数，结论依然是 **$U \leq 0$**。
